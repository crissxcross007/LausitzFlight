# Lausitz F.L.I.G.H.T

Statische GitHub-Pages-Website. Hauptseiten: index.html, leistungen.html, aufnahmen.html, ueber-mich.html, kontakt.html.

## Zentrale Pflege
- Menü: header.html
- Footer: footer.html
- Gestaltung: style.css
- Verhalten und Bildansicht: site.js
- Filme: data/videos.json; youtubeId auf die 11-stellige Video-ID setzen. Ohne ID bleibt der Bereich ohne Abspielbutton. YouTube wird erst nach Aktivierung geladen.

## Vorschau vor dem geschäftlichen Start
Preise sind Vorschläge und sichtbar als Entwurf markiert. Kontaktdaten, Impressum, Datenschutz und finale Preise müssen ergänzt werden. Danach noindex bewusst entfernen und Sitemap einreichen. Keine Kontaktdaten erfinden. Angaben zu Kundenprojekten nur mit gesichertem Inhalt ergänzen.

## Bilder
Eigene Aufnahmen, als WebP in zwei Größen. Originale werden nicht verändert. Fotos der Flotte sind teilweise Gruppenbilder; Neo hat noch einen markierten Platzhalter. Ältere Bilddateien bleiben im Repository erhalten.
